# 界面采用高信息密度的深色极客风格

> **已被 [ADR-0007](0007-light-console-ui-supersedes-0005.md) 取代。** 控制台现在是浅色留白风格。
> 本文保留作为"当时为什么这么选"的记录，**不要再照着它改样式**。

控制台的视觉语言参考 Command Code（commandcode.ai）：纯黑底、等宽字体承载数据、靛蓝单色强调、极淡网格底、`//` 分区注释配方括号状态标签。

真实的权衡是牺牲"开箱友好"——第一次打开的人不会觉得它亲切。换来的是同样屏幕面积能放更多可扫数据：配置页一屏放完全部分组与自定义表单，用量页一屏放完配额、曲线与明细表。

另一个考虑是**状态色的可读性**。全屏只有一个装饰性强调色（靛蓝），绿与红只用于状态，因此 `ACTIVE` 与 `HTTP 403` 这类标记在满屏灰阶里一眼可辨，不跟主题色抢注意力。

改动成本不对称：换几个色值很容易，但那不叫改风格。这套语言的核心是**信息密度优先**，真要改成通用的浅色后台，五个页面的布局与层级都要重排。当时的样板页 `app\design\ui-mock.html` **现已不在仓库里**；配色与间距的当前依据是 `app\static\app.css` 顶部的 `:root`。
